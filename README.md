# Node.js Backend Practice 🚀

This repository contains my backend development practice using **Node.js** and **Express.js**.
The goal of this project is to strengthen my understanding of backend concepts and implement them through small practical examples.

## 📚 Concepts Covered

* Express.js Server Setup
* Middleware Usage
* Routing in Express
* Cookies Handling
* Authentication Basics
* Password Hashing with **bcrypt**
* Request Body Parsing
* EJS Template Rendering

## 🛠 Tech Stack

* Node.js
* Express.js
* EJS
* bcrypt
* cookie-parser
* JavaScript (ES Modules)
